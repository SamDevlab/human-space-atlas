# Competitive notes

The category is not empty. Existing products already prove demand:

- KeepTrack.Space: feature-rich 3D satellite/debris tracking, search, sensors and analysis.
- Stuff in Space and descendants/forks: classic WebGL visualization of Earth-orbit objects.
- ExoAtlas: browser-based real-time 3D Solar System and scientific catalog aggregation.
- NASA Eyes / JPL experiences: authoritative mission and Solar System visualization.

## Differentiation hypothesis

Human Space Atlas should not compete on "show dots around Earth" alone. Its defensible product shape is:

**One navigable history-and-live map of artificial human presence from LEO to deep space.**

Core differentiators to validate:

1. Seamless Earth-orbit ↔ deep-space transition.
2. Human-made-object-first information architecture.
3. OMM-first ingestion for modern catalog IDs.
4. Timeline/history as a first-class interaction, not only current position.
5. Clean consumer-grade UI on top of source-transparent scientific data.
