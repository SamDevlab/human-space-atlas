# Exploration spacecraft model

`cassini-huygens-b.glb` is the Cassini orbiter model published by NASA/JPL/Solar System Simulator.

- Source: https://science.nasa.gov/3d-resources/cassini-huygens-b/
- Download: https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/model/cassini-huygens-%28b%29/Cassini-Huygens%20%28B%29.glb
- License/usage: NASA 3D Resources asset, free to download and use according to NASA's resource listing.

`voyager-probe-b.glb` is the textured Voyager Probe (B) model published by NASA.

- Source: https://science.nasa.gov/3d-resources/voyager-probe-b/
- Download: https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/model/voyager-probe-%28b%29/Voyager%20Probe%20%28B%29.glb
- License/usage: NASA 3D Resources asset, free to download and use according to NASA's resource listing.
